PROJECT 04

AI Supply Chain Intelligence – SCI-BOT

Delay Detection & Solution BOT — an AI-powered multi-agent supply chain intelligence system for shipment tracking, delay detection, supplier analysis, weather analysis, risk assessment and business decision support.

View Project → GitHub Images LinkedIn
Python LangGraph LangChain Multi-Agent AI Groq LLM RAG FAISS Sentence Transformers Conversation Memory FastAPI Gradio
PROBLEM STATEMENT

Making supply-chain decisions more intelligent.

Supply chain and logistics companies often face challenges in tracking shipments, identifying delays, monitoring supplier performance, evaluating weather impact and assessing business risks.

Traditional Challenge

  • Manual shipment analysis
  • Delayed identification of risks
  • Limited supplier visibility
  • Weather impact requires manual analysis
  • Difficult to determine next actions

SCI-BOT Solution

SCI-BOT combines multi-agent AI, RAG, conversation memory and external business tools to analyse shipment situations and provide actionable recommendations.

OBJECTIVES

From shipment tracking to intelligent decisions.

🚚 Shipment Tracking

Track shipments using multiple search methods.

⏱ Delay Detection

Identify potential shipment delays automatically.

📚 Knowledge Retrieval

Retrieve relevant supply-chain information using RAG.

🏭 Supplier Analysis

Analyse supplier availability and related risks.

🌦 Weather Analysis

Evaluate weather conditions that may affect delivery.

⚠️ Risk Assessment

Evaluate shipment risks and generate business insights.

MULTI-AGENT ARCHITECTURE

Specialized agents working together.

Instead of relying on a single AI component, SCI-BOT divides responsibilities among specialized agents coordinated through a LangGraph workflow.

01

Input Agent

Accepts and validates the customer request.

02

Customer Lookup Agent

Retrieves relevant customer information.

03

RAG Retriever Agent

Retrieves relevant supply-chain knowledge.

04

Shipment Agent

Retrieves shipment information and status.

05

Supplier Agent

Retrieves and analyses supplier information.

06

Weather Agent

Retrieves weather conditions affecting shipments.

07

Risk Analysis Agent

Evaluates shipment and business risks.

08

LLM Agent

Uses Groq LLM to generate the business report.

09

Output Agent

Displays the final AI-generated response.

LANGGRAPH WORKFLOW

From customer request to professional AI report.

Customer ↓ Input Validation ↓ Customer Lookup Agent ↓ RAG Retrieval Agent ↓ Shipment Agent ↓ Supplier Agent ↓ Weather Agent ↓ Risk Analysis Agent ↓ LLM Agent — Groq ↓ Professional AI Report
RETRIEVAL-AUGMENTED GENERATION

Domain knowledge before AI reasoning.

SCI-BOT retrieves domain-specific knowledge before generating responses. Sentence Transformers create embeddings and FAISS performs semantic retrieval to provide relevant context to the Groq LLM.

Documents ↓ Text Splitter ↓ Sentence Transformer Embeddings ↓ FAISS Vector Database ↓ Semantic Search ↓ Relevant Context ↓ Groq LLM
CONVERSATION MEMORY

Context-aware supply-chain conversations.

Conversation memory maintains interaction context, enabling follow-up questions, reducing repeated requests and improving conversation continuity.

Context-Aware Responses

Maintains relevant conversation context across interactions.

Follow-Up Questions

Users can continue the conversation without repeating previous information.
